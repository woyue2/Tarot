# 多模态模型牌面描述生成 Prompt 模板

## 使用方法

1. 打开支持视觉识别的多模态模型（ChatGPT GPT-4V / Claude / Gemini / 通义千问-VL 等）
2. 上传对应牌面图片（`塔罗言传/图片/` 目录下的 webp 文件）
3. 复制下方的 prompt 模板，替换其中的 [牌名] 和 [文件名]
4. 发送给模型，获取生成的描述
5. 将生成的描述粘贴给我，我会整理到对应文件中

---

## 通用 Prompt 模板

```
请仔细观察这张韦特塔罗牌面图片，按以下格式输出视觉描述（基于正位视角，以观众视角为准）。

牌名：[牌名]
文件名：[文件名]

要求：
1. 朝向必须准确：人物面朝画面右侧=向右，面朝画面左侧=向左，面朝观众=向前
2. 位置关系必须准确：前/后、左/右、上/下、远/近
3. 符号要列全：所有可见的重要符号都要列出，并标注其在画面中的位置
4. 易错点：指出这张牌最容易看错的细节（朝向、位置、数量等）
5. 不要加入牌义解释，只描述画面本身（自然流解牌时再解读含义）

输出格式：

## [牌名] | [文件名]

**绘画类型**：[寓言象征画(大牌)/人物肖像画(宫廷牌)/叙事场景画(数字牌)/符号显现画(Ace牌)]
**正逆位参考**：以下描述基于正位牌面

### 朝向
[左/右/前/对视/背对/无人物] — [具体描述人物面朝方向，以观众视角为准]

### 姿态
[开放/封闭/动态/静态/劳作/跪拜/无人物] — [具体描述人物动作和状态]

### 主色调
[列出主要色彩及其给人的感受]

### 天气/光线
[晴空/暴风雨/黄昏/白雪/暗淡/其他] — [具体描述天气和光线情况]

### 关键符号
- [符号1]（位置）：符号本身的形态描述
- [符号2]（位置）：符号本身的形态描述
- ...

### 画面故事
[一句话描述牌面"发生了什么"，只描述画面，不解释含义]

### 易错点
[列出1-3个容易看错的细节]
```

## 重点注意事项

1. **朝向是第一优先级**：一定要看清人物面朝画面左侧还是右侧
2. **位置关系**：城堡、山、水、太阳等背景元素，在人物的哪一侧（左/右/后/前）
3. **人物数量**：画面中有几个人物，分别在什么位置
4. **符号数量**：比如权杖几把、圣杯几个、星币几枚
5. **只描述，不解读**：不要说"象征着XX"，只说"画面中有XX，在XX位置"
6. **易错点字段很重要**：标注这张牌最容易看错的地方
