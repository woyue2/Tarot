# 牌阵专属提示词规范（审阅稿）

> 状态：内容已审核，字段模型与 32 个可选预设已于 2026-08-09 落地。
>
> 依据：[塔罗牌阵大全_适用场景与使用方法.txt](塔罗牌阵大全_适用场景与使用方法.txt)。目标是让每种牌阵都得到对应的解读指令，而不是只替换位置名称。

## 1. 结论与边界

每个牌阵需要**少量但明确的专属提示词指令**。不同牌阵的差异主要在解读顺序、牌间比较、综合结论的推理规则和自然流观察，不在于重复一整套“逐牌解释”的大提示词。

模型提示词应由三部分拼装：

1. **通用基础指令**：回应问题、逐牌解读、尊重正逆位、使用画面/符号/人物朝向、将结果表述为趋势而非宿命、给出可执行建议。
2. **牌阵数据**：名称、全部位置、每张牌所处位置、问题、正逆位与视觉资料。
3. **本规范中的专属指令**：阅读顺序、对比组、关注点、综合产出要求。

不应为每个牌阵复制一份完整 system prompt；否则通用安全限制、输出 JSON 契约和自然流原则会逐渐漂移。

## 2. 统一数据结构（建议）

```ts
type SpreadGuidance = {
  /** 模型组织正文时优先解读的位置编号；未给出则按 1..n。 */
  readingOrder?: readonly number[];
  /** 必须作出关联判断的位置组。 */
  comparisons?: readonly {
    positions: readonly number[];
    instruction: string;
  }[];
  /** 在逐牌之后必须完成的整体观察。 */
  focus: readonly string[];
  /** 对 storyline / actionAdvice 的额外约束。 */
  synthesis: string;
  /** 对问题类型、牌组或结果表述的边界。 */
  guardrails?: readonly string[];
};
```

每次模型调用均应明确要求：

> 先鸟瞰整体色调、元素、大阿尔卡那比例与人物朝向；再按本牌阵指定顺序逐位解释；随后完成指定对比；最后将牌阵串成一条故事线，提供行动建议。位置含义是框架，不可用脱离牌面与相邻牌的模板化断语代替。

`guidance` 是给模型的上下文，不需要暴露给最终用户；最终输出仍保持现有的 `cards / storyline / actionAdvice` 契约。

## 3. 通用自然流指令（所有牌阵）

- 先整体后局部：不把每张牌解释成互不相干的条目。
- 记录重复符号、色调、花色/元素、人物视线和方向；只在与问题和牌阵位置相关时纳入结论。
- 正逆位表示当前趋势或可调整的课题，不作绝对预测。
- 大阿尔卡那多时可说明主题具有较强的阶段性/人生课题意味；小阿尔卡那多时强调可行动的日常层面。
- 对涉及关系的牌阵，不把牌面当作读取第三方隐私或替代沟通的事实依据；使用“可能的互动模式/当前趋势”表述。
- 建议必须落到问卜者可控制的行为，避免制造恐惧或宣称结果注定。

## 4. 逐牌阵指令清单

表中“位置”即最终应注入模型的 position names；“专属指令”需写入 `guidance`。实现时每一行对应一个可选预设，而不只是一个视觉布局。

### 4.1 基础与三张牌预设

| ID（建议） | 牌阵 / 位置 | 解读顺序与专属指令 |
|---|---|---|
| `single` | 核心讯息 | 使用“三词”：情绪词、符号词、信息词；重点说明第一直觉、身体反应、主色调、人物朝向与关键符号如何回应问题。|
| `triple_timeline` | 圣三角（原文 1.2，**不计入**下方 14 种变体）：过去 / 现在 / 未来 | `1→2→3`；中间牌为核心，1 与 3 构成来龙去脉；将三张串成开端→发展→结果，并观察人物朝向与元素流动。|
| `triple_problem_solving` | 问题本质 / 原因 / 解决方案 | `1→2→3`；方案必须回应原因，而非只给单张牌义。|
| `triple_obstacle` | 现状 / 障碍 / 建议 | `1→2→3`；将障碍翻译成可处理的卡点，建议必须具体。|
| `triple_action` | 情境 / 行动 / 结果 | `1→2→3`；明确结果是采取位置 2 行动后的趋势。|
| `triple_control` | 能改变的 / 不能改变的 / 未意识到的 | `1→2→3`；清楚区分可控与不可控，并把第 3 张转为觉察练习或下一步。|
| `triple_relationship` | 你 / 对方 / 关系现状 | `1↔2→3`；比较双方能量与视线，再说明它们如何共同构成关系现状。|
| `triple_relationship_needs` | 你想要的 / 对方想要的 / 关系走向 | `1↔2→3`；判断需求的共鸣、错位或需协商之处，不断言对方内心事实。|
| `triple_relationship_tension` | 让你们在一起的 / 让你们分开的 / 需要关注的 | `1↔2→3`；第 3 张须成为连接与张力之间的改善焦点。|
| `triple_decision` | 选项 A / 选项 B / 如何做决定 | `1↔2→3`；不宣判“唯一正确选项”，说明两个选项的代价、价值与决策准则。|
| `triple_opportunity` | 机会 / 挑战 / 结果 | `1→2→3`；结果要同时受机会与挑战制约。|
| `triple_strengths` | 优势 / 劣势 / 建议 | `1↔2→3`；建议应利用优势、补足劣势。|
| `triple_body_mind_spirit` | 身 / 心 / 灵 | `1→2→3`；说明三个层面的一致或失衡，并给平衡建议。|
| `triple_consciousness` | 显意识 / 潜意识 / 超意识 | `1→2→3`；对比显性目标与潜在动力，第 3 张作为更高视角而不是权威命令。|
| `triple_states` | 物质状态 / 精神状态 / 情绪状态 | `1→2→3`；识别哪个层面对其他层面施压，并给跨层面的调整建议。|
| `triple_habit` | 停止做什么 / 开始做什么 / 继续做什么 | `1→2→3`；输出必须明确列出 stop / start / continue 三项行动。|

**已确认：** 原文正文列出以上 **14** 种三张牌变体；圣三角来自原文 1.2，不计入变体数量。产品统一使用“14 种预设”，不臆造缺少的 6 种。

### 4.2 四至八张牌阵

| ID（建议） | 牌阵 / 位置 | 解读顺序与专属指令 |
|---|---|---|
| `diamond` | 过去 / 现在（上） / 现在（下） / 未来 | `1→2+3→4`；必须综合 2、3 的互补或矛盾，不能分别读完就结束。|
| `elements` | 火：行动 / 风：沟通 / 水：情感 / 土：现实 | `1→2→3→4`；结论固定回答“做什么、说什么、感受什么、现实上有什么资源/边界”。|
| `gypsy_cross` | 心态 / 状况 / 举措 / 环境 / 关系未来 | `1→2→3→4→5`；先读四张外围，最后以中心未来牌综合；环境必须说明被忽视的外部因素。|
| `two_paths` | 当前状况 / A 过程 / B 过程 / A 结果 / B 结果 | `1→2→4→3→5`；分别比较 `(2,4)` 和 `(3,5)` 的过程与结果、大/小牌比例、人物活力与能量流；若双结果都不理想，允许提出第三路径。|
| `pentacle_week` | 本周 / 下周 / 第三周 / 第四周 / 第五周 | `1→2→3→4→5`；解释相邻周之间的过渡，不把远期月份当确定预言。|
| `pentacle_element` | 灵性 / 行动 / 情感直觉 / 现实资源 / 思维沟通 | `1→2→3→4→5`；以位置 1 统领全局，判断五个维度的强弱与失衡，给出恢复平衡的优先级。|
| `pentacle_issue` | 现状 / 障碍 / 过去 / 未来 / 建议 | 建议阅读为 `3→1→4→5`，并单独强调位置 2 是改善线索而非敌人；故事线为“成因→现在→未来→改善点”。|
| `hexagram` | 过去 / 现在 / 未来 / 对策 / 环境或对方 / 自己心态 / 结果 | `1→2→3→5↔6→4→7`；上三角为时间流，下三角为人与对策；对比 5、6 的认知差距；位置 4 必须解释如何连接问题与结果；位置 7 必须综合前六张。|
| `venus` | 自己想法 / 对方想法 / 对自己的影响 / 对对方的影响 / 双方障碍 / 结果 / 未来自己心情 / 未来对方心情 | `1→2→3→4→7→8→5→6`；对比 `(1,2)`、`(3,4)`、`(7,8)`；位置 5 是关键因果点，位置 6 为当前趋势而非定数。|
