## 0. 一句话结论

`docs/自然流解牌完整指南.txt` 目前**只是仓库里的一份参考文档**，没有被任何运行时代码接入。真正驱动解牌的是另一套方法论（「最后一舞塔罗」灵性直觉 + 动量/价值打分）。

**如果要真正实现自然流解牌，单纯改提示词不够**——提示词只决定「语气/风格」，而方法论实际被「输出 JSON 契约 + 确定性计分引擎 + 牌阵锁」三层共同锁定。

## 2. 自然流解牌的「基因」现在哪里有

自然流解牌指南的核心技巧（第二章「牌面视觉观察」）**有一部分已经被吸收**，体现为喂给模型的输入字段：

- `visualDescription`：朝向 / 姿态 / 主色调 / 光线 / 画面故事（来自 `data/牌面视觉描述/*.md`）
- `symbols`：关键符号 + 含义

这两项是「画面优先」那一套，和自然流第二章一致。

但自然流的**骨架并未实现**：

- 第 3–4 章「牌间能量传递 / 花色·数字·大牌比例 / 重复主题 / 故事弧线」——没有任何跨牌计算，模型只拿到 5 张裸牌自行推断；
- 第 6 章「直觉 / 第一感觉 / 身体反应」——AI 无法真正产生，只能作为风格指令模拟；
- 第 7 章「自由形式 / 无牌阵」——被 5 张时间流牌阵焊死，无法支持。

## 3. 如果实现自然流：只改提示词够吗？

### 3.1 提示词能改到的（风格层）

真正下指令给模型的是两层：

1. **system 指令**（`apps/desktop/src/main/model.ts` 第 98 / 137 / 230 行）：
   > 「你是一个克制、生活化、有共情力的塔罗解读助手。牌已由本地程序抽取并保存，你只能解释输入，不得换牌、补牌或声称确定预测未来。**严格根据牌面、固定分值和方法论输出**。」
2. **方法论 flavor 字段**：`methodology.json` 的 principles 经 `methodologyStyle` 流进输入的 `methodology.style`，模型能看到。

改这两处可以：把「固定分值导向」改成「鸟瞰整体 / 牌间能量流 / 画面优先 / 直觉引导 / 叙事流动」，并替换方法论原则为自然流五条。

### 3.2 提示词改不掉的（骨架层，全是代码/契约）

| 缺失 / 卡点 | 现状 | 位置 |
|---|---|---|
| **输出契约强制动量/价值** | 输出 JSON Schema 中 `momentumInterpretation`、`valueInterpretation` 为 `required` 且 `additionalProperties:false`；Zod 同步强制 | `model.ts:46-61` + `JSON_STRUCTURE_PROMPT:64` + `schemas.ts:59-74` + 移动端镜像 `apps/mobile/src/runtime/model-provider.ts` |
| **确定性计分脊柱** | `calculateMomentumValue` 算出动量/价值并塞进输入与输出结构 | `packages/core/src/scoring.ts`、`interpretation-input.ts` 的 `calculation` 字段 |
| **无跨牌模式信号** | 花色比例 / 大牌小牌比例 / 重复数字符号 / 相邻关系未预计算，模型只能自行推断 | 需新增「模式聚合」计算（类似 `calculateMomentumValue` 的兄弟函数）+ 输入 schema 新字段 |
| **牌阵焊死 5 张时间流** | `spread` 用 `z.literal("five_card_timeline_v1")` + 5 字面量 tuple 锁死；牌数 5 在五层锁死 | `schemas.ts:16-26`、`interpretation-input.ts`；自由形式需先解「牌阵可扩展性」技术债 |
| **UI 渲染锚定旧结构** | 解读视图围绕 headline / storyline / momentum / value / actionAdvice 排版 | 渲染组件需随输出形状改动 |

**结论**：提示词能放大「画面优先 / 叙事流动」的调性，但动不了动量/价值这个强制骨架，也开不了无牌阵。所以是「自然流调性」，不是「自然流范式」。

## 4. 两条落地路径

### 路径 1 — 最小改动（基本只动 prompt + 方法论文档）
- 改写 system 指令为自然流风格，去掉「固定分值」强调；
- 把 `methodology.json` 的 principles 换成自然流原则；
- 保留动量/价值骨架，指示模型把动量/价值编织进整体叙事。
- **工作量**：一下午级。**结果**：自然流「调性」，仍锚定动量/价值。

### 路径 2 — 真切换范式
- 改输出 Schema：去掉/可选化 `momentumInterpretation` / `valueInterpretation`，换成自然流字段（`energyFlow` 牌间能量、`overallTheme` 整体主题、`patterns` 重复主题、`holisticReading` 整体读）；
- 决定计分引擎去留（降级为辅助信号 or 移除，连带 `calculation` 字段与 schema）；
- 可选：新增跨牌「模式聚合」计算并喂入输入；
- 视情况解锁牌阵系统以支持自由形式；
- UI 随输出形状改版。
- **工作量**：跨 schema / runtime / 两端 UI 的中等重构。
